# Redes de Computadoras

Este espacio académico reunirá progresivamente las guías, los laboratorios, las configuraciones y el código utilizado en la asignatura **Redes de Computadoras**.

> 🚧 **Página en construcción:** los recursos se incorporarán por unidades durante el desarrollo de la materia.

- Fundamentos de redes y modelo TCP/IP

- Enrutamiento inter-VLAN y routing
- DHCPv4, IPv6, SLAAC y DHCPv6
- Seguridad y resolución de problemas

## Recursos que se publicarán

- Guías de configuración
- Laboratorios de Cisco Packet Tracer
- Configuraciones de Cisco IOS
- Ejercicios y proyectos integradores
- Material de evaluación y apoyo
